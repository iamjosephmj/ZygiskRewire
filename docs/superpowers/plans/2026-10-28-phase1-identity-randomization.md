# Phase 1: Build-Time Identity Randomization — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every build of ZygiskRewire produces binaries, module files, and log tags carrying a fresh random identity; the strings "zygisk"/"ReZygisk" no longer appear in any build output.

**Architecture:** A generator script emits `build/identity.mk` (make vars) and `module/identity.env` (shell vars) per build. `common.mk` includes the make vars and injects them as `-D` string-literal macros into every C compile. C sources stop hardcoding identifying literals and consume the macros. Module-side files (`module.prop`, `sepolicy.rule`, `customize.sh`, `post-fs-data.sh`, webroot) are rendered from `@@TOKEN@@` templates at zip-build time.

**Tech Stack:** GNU make, NDK clang (existing toolchain via `common.mk`), bash, Magisk/KSU/APatch module zip format.

**Spec:** `docs/superpowers/specs/2026-10-28-zygiskrewire-app-space-design.md` (§1 Build-time identity randomization; rev 3)

## Global Constraints

- All code and comments in English (user global instruction).
- Preserve GPL-3.0 LICENSE and upstream attribution; do not touch `LICENSE` or `NOTICE`.
- Requires NDK r29 (`NDK_VERSION ?= 29.0.13113456` in `common.mk`) and `ANDROID_HOME` set (defaults to `~/Android/Sdk`).
- `build/` is already gitignored (`.gitignore:5`) — generated identity files must live under `build/` and must never be committed.
- Macro names reuse ReZygisk's existing names wherever one exists (`TMP_PATH`, `SOCKET_NAME`, `SOCKET_FILE_NAME`, `LOG_TAG`, `MOD_ID`) so diffs stay small; new macros: `DAEMON_BIN`, `PTRACER_BIN`, `LIB_NAME`, `CP_BASE`, `STATE_NAME`, `SEPOL_TYPE`, `TAG`.
- Identity values must satisfy: lowercase hex + leading letter (valid module id, valid C macro string, valid SELinux type token, valid filename). No value may collide with Android system names.

### Task 1: Identity generator script

**Files:**
- Create: `scripts/gen_identity.sh`
- Create (generated, not committed): `build/identity.mk`, `module/identity.env`

**Interfaces:**
- Produces: `build/identity.mk` defining make vars `ID_MOD_ID, ID_DAEMON_BIN, ID_PTRACER_BIN, ID_LIB_NAME, ID_TMP_PATH, ID_SOCK_MON, ID_CP_BASE, ID_STATE_NAME, ID_SEPOL_TYPE, ID_TAG, ID_HASH`; `module/identity.env` defining the same names as shell `export` lines. Task 2 consumes `identity.mk`; Tasks 3–5 consume the macros; Task 5 consumes `identity.env`.

- [ ] **Step 1: Write the generator**

```bash
#!/usr/bin/env bash
# scripts/gen_identity.sh — generate this build's random identity.
# Usage: scripts/gen_identity.sh [outdir]   (default: build)
set -euo pipefail
OUT="${1:-build}"
MOD_DIR="$(cd "$(dirname "$0")/.." && pwd)"
mkdir -p "$OUT"

H="$(od -An -N32 -tx1 /dev/urandom | tr -d ' \n')"

MOD_ID="syscfg-${H:0:8}"
DAEMON_BIN="${H:8:6}d"        # installed as ${DAEMON_BIN}32 / ${DAEMON_BIN}64
PTRACER_BIN="${H:14:6}p"      # installed as ${PTRACER_BIN}32 / ${PTRACER_BIN}64
LIB_NAME="lib${H:20:8}.so"
TMP_PATH="/data/adb/${MOD_ID}"
SOCK_MON="m${H:28:8}"         # was: init_monitor
CP_BASE="c${H:36:6}"          # sockets: ${CP_BASE}32.sock / ${CP_BASE}64.sock
STATE_NAME="s${H:42:6}.json"  # was: state.json
SEPOL_TYPE="t${H:48:8}"       # was: zygisk_file
TAG="w${H:56:8}"              # log tag prefix, replaces all "zygisk*" tags

HASH_INPUT="${MOD_ID}${DAEMON_BIN}${PTRACER_BIN}${LIB_NAME}${SOCK_MON}${CP_BASE}${SEPOL_TYPE}${TAG}"
ID_HASH="$(printf '%s' "$HASH_INPUT" | sha256sum | cut -c1-16)"

cat > "$OUT/identity.mk" <<EOF
# Generated by scripts/gen_identity.sh — DO NOT COMMIT, DO NOT EDIT.
ID_MOD_ID := ${MOD_ID}
ID_DAEMON_BIN := ${DAEMON_BIN}
ID_PTRACER_BIN := ${PTRACER_BIN}
ID_LIB_NAME := ${LIB_NAME}
ID_TMP_PATH := ${TMP_PATH}
ID_SOCK_MON := ${SOCK_MON}
ID_CP_BASE := ${CP_BASE}
ID_STATE_NAME := ${STATE_NAME}
ID_SEPOL_TYPE := ${SEPOL_TYPE}
ID_TAG := ${TAG}
ID_HASH := ${ID_HASH}
EOF

cat > "$MOD_DIR/module/identity.env" <<EOF
# Generated by scripts/gen_identity.sh — consumed by customize.sh at install.
export ID_MOD_ID='${MOD_ID}'
export ID_DAEMON_BIN='${DAEMON_BIN}'
export ID_PTRACER_BIN='${PTRACER_BIN}'
export ID_LIB_NAME='${LIB_NAME}'
export ID_TMP_PATH='${TMP_PATH}'
export ID_HASH='${ID_HASH}'
EOF

echo "identity written to $OUT/identity.mk and module/identity.env (id=${MOD_ID})"
```

- [ ] **Step 1: Write the renderer**

```bash
#!/usr/bin/env bash
# scripts/render_module.sh — substitute @@TOKENS@@ in module files at zip build.
# Usage: scripts/render_module.sh <file>...
set -euo pipefail
ENV_FILE="module/identity.env"
[ -f "$ENV_FILE" ] || scripts/gen_identity.sh build
# shellcheck disable=SC1091
source "$ENV_FILE"

render() {
  local f="$1"
  sed -i \
    -e "s|@@MOD_ID@@|${ID_MOD_ID}|g" \
    -e "s|@@DAEMON_BIN@@|${ID_DAEMON_BIN}|g" \
    -e "s|@@PTRACER_BIN@@|${ID_PTRACER_BIN}|g" \
    -e "s|@@LIB_NAME@@|${ID_LIB_NAME}|g" \
    -e "s|@@TMP_PATH@@|${ID_TMP_PATH}|g" \
    -e "s|@@SEPOL_TYPE@@|$(grep -oP '^ID_SEPOL_TYPE := \K.*' build/identity.mk)|g" \
    -e "s|@@TAG@@|$(grep -oP '^ID_TAG := \K.*' build/identity.mk)|g" \
    "$f"
}
for f in "$@"; do render "$f"; done
```

- [ ] **Step 1: Write the checker**

```bash
#!/usr/bin/env bash
# scripts/check_identity.sh — assert two consecutive builds are identity-disjoint
# and carry zero zygisk/rezygisk tokens.
set -euo pipefail
cd "$(dirname "$0")/.."

check_clean() { # $1 = dir
  local hits=0
  while IFS= read -r -d '' f; do
    if strings "$f" 2>/dev/null | grep -qiE 'zygisk|rezygisk'; then
      echo "IDENTITY LEAK in $f:"; strings "$f" | grep -iE 'zygisk|rezygisk' | head -5; hits=1
    fi
  done < <(find "$1" -type f \( -name '*.so' -o -perm -u+x \) -print0)
  return "$hits"
}

rm -rf build/check-a build/check-b
scripts/gen_identity.sh build/check-a
make BUILD_DIR=build/check-a debug >/dev/null
scripts/gen_identity.sh build/check-b
make BUILD_DIR=build/check-b debug >/dev/null

check_clean build/check-a && check_clean build/check-b || { echo "FAIL: leaks found"; exit 1; }

A="$(grep ID_HASH build/check-a/identity.mk)"; B="$(grep ID_HASH build/check-b/identity.mk)"
[ "$A" != "$B" ] || { echo "FAIL: identities identical across builds"; exit 1; }
echo "PASS: builds are identity-disjoint and neutral"
```
